# 🛒 Grozo – Real-Time Grocery Delivery Platform

Grozo is a modern full-stack grocery delivery platform built using the MERN Stack and Next.js.  
The platform provides secure authentication, OTP verification, role-based dashboards, online payments, and real-time order updates for users, admins, and delivery partners.

---

# 🚀 Features

## 🔐 Authentication & Security
- Secure authentication using **NextAuth.js**
- Login/Register using:
  - Credentials Authentication
  - OAuth Authentication
- OTP verification for account security
- JWT-based session handling
- Protected routes and secure APIs

---

## 👥 Role-Based Access
Users can choose their role after authentication:

- 👤 User
- 🛡️ Admin
- 🚚 Delivery Partner

Each role has its own dashboard and permissions.

---

## 📱 Phone Number Verification
- Users must verify their phone number after signup/login
- OTP verification flow for secure onboarding

---

## ⚡ Real-Time Features
Integrated **Socket.IO** for real-time functionality:

- Live order status updates
- Instant notifications
- Dynamic dashboard updates
- Real-time delivery tracking

---

## 🛍️ Grocery Platform Features
- Browse grocery products
- Add products to cart
- Place orders securely
- Manage orders
- Responsive and modern UI

---

## 💳 Payment Integration
- Secure online payments using **Razorpay**
- Smooth checkout experience

---

## ☁️ Cloud Integration
- Cloudinary integration for image upload and storage
- Optimized media handling

# 🔄 Application Flow

1️⃣ User registers or logs in using:
- Credentials Authentication
- OAuth Authentication

2️⃣ OTP verification is completed

3️⃣ User selects role:
- Admin
- User
- Delivery Partner

4️⃣ User enters phone number

5️⃣ User is redirected to their dashboard

6️⃣ Users can place orders and receive real-time updates
